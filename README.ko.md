# Calendar of Notes

[English](README.md) | 한국어

Obsidian의 기존 노트를 날짜별로 탐색할 수 있는 빠르고 간결한 로컬 캘린더입니다.

Obsidian 1.7.2 이상이 필요합니다.

Calendar of Notes는 파일명이나 노트 속성 또는 두 기준 모두에서 날짜를 찾습니다. 날짜를 선택해 노트를 바로 열거나, 사이드바를 벗어나지 않고 해당 날짜의 모든 노트를 확인할 수 있습니다.

> [!NOTE]
> Calendar of Notes는 현재 초기 공개 베타 버전입니다. 중요한 Vault에 적용하기 전에 별도의 테스트 Vault에서 먼저 확인하세요.

## 주요 기능

- 사이드바와 모바일 서랍에 맞게 설계된 월간·주간·연간 보기
- 이전/다음 이동, 월·연도 선택, 날짜 직접 이동, 오늘로 이동
- 간편한 날짜 입력: `20260730`을 입력하면 `2026-07-30`으로 자동 변환
- 스마트 열기: 노트가 하나면 바로 열고, 여러 개면 목록 표시
- 캘린더 하단 목록, 팝업 목록 또는 목록 숨김
- 날짜별 노트 점 표시 최대 3개와 추가 노트 `+` 표시
- 파일명, frontmatter 속성, 속성 우선 대체, 두 기준 모두를 이용한 날짜 매칭
- 파일명 날짜 형식 4종과 날짜 위치를 간단히 선택하고, 필요할 때만 고급 정규식 사용
- 여러 frontmatter 날짜 속성 사용
- 포함·제외 폴더 및 태그 필터
- 현재 탭, 새 탭 또는 새 분할 영역으로 노트 열기
- 노트 정렬, 경로 표시, 한 주의 시작 요일 설정
- Obsidian 언어에 따른 영어·한국어 자동 전환
- 데스크톱·모바일 반응형 UI와 키보드 날짜 탐색
- Obsidian Vault 및 Metadata Cache 이벤트를 이용한 증분 메모리 인덱싱

Calendar of Notes는 메타데이터를 읽고 노트를 여는 기능만 수행합니다. 노트를 생성하거나 이름을 바꾸거나 수정·삭제하지 않습니다.

## 설치

### 커뮤니티 플러그인

Obsidian 커뮤니티 플러그인 디렉터리에 등록된 이후에는 다음과 같이 설치할 수 있습니다.

1. **설정 → 커뮤니티 플러그인**을 엽니다.
2. **탐색**을 선택하고 **Calendar of Notes**를 검색합니다.
3. 플러그인을 설치하고 활성화합니다.

### 수동 설치 또는 베타 테스트

1. 동일한 GitHub Release에서 `main.js`, `manifest.json`, `styles.css`를 내려받습니다.
2. Vault 안에 다음 폴더를 만듭니다.

   ```text
   <vault>/.obsidian/plugins/calendar-of-notes/
   ```

3. 세 파일을 해당 폴더에 복사합니다.
4. Obsidian을 다시 불러온 후 **설정 → 커뮤니티 플러그인**에서 활성화합니다.

릴리즈가 생성된 후에는 [BRAT](https://github.com/TfTHacker/obsidian42-brat)에 이 저장소 주소를 추가하여 베타 버전을 설치할 수도 있습니다.

## 시작하기

리본의 캘린더 아이콘이나 명령 팔레트에서 Calendar of Notes를 엽니다. 상단의 보기 전환 버튼을 사용할 수 있습니다.

| 버튼 | 보기 |
| --- | --- |
| `M` | 월간 |
| `W` | 주간 |
| `Y` | 연간 |

화살표 버튼으로 이전·다음 기간으로 이동합니다. 상단 제목을 선택하면 월이나 연도를 고를 수 있고, 과녁 버튼으로 오늘로 돌아가거나 캘린더 검색 버튼으로 날짜를 직접 입력할 수 있습니다.

날짜 이동에서는 `YYYY-MM-DD`뿐 아니라 `20260730`과 같은 숫자 8자리 입력도 지원합니다.

## 날짜 매칭

기본 전략은 **속성 우선, 없으면 파일명**입니다.

1. 설정한 frontmatter 속성들에서 올바른 날짜를 모두 사용합니다.
2. 어느 속성에도 올바른 날짜가 없으면 파일명에서 날짜를 찾습니다.

### 속성 예시

```yaml
---
date: 2026-07-30
created: 2026-07-29
published:
  - 2026-08-01
---
```

속성명은 한 줄에 하나씩 입력합니다. 설정한 모든 속성에서 유효한 날짜를 가져옵니다. `2026-07-30T15:30:00+09:00`과 같은 ISO 날짜·시간은 UTC로 변환하지 않고 작성된 날짜 그대로 사용합니다.

### 파일명 예시

| 날짜 형식 | 매칭 예시 |
| --- | --- |
| `YYYY-MM-DD` | `2026-07-30 노트 제목.md` |
| `YYYY.MM.DD` | `2026.07.30 노트 제목.md` |
| `YYYY_MM_DD` | `2026_07_30 노트 제목.md` |
| `YYYYMMDD` | `20260730 노트 제목.md` |
| 직접 패턴 입력 | ISO 날짜를 캡처하는 고급 정규식 |

기본 형식에서는 날짜가 파일명 시작 부분, 어디든 또는 파일명 전체에 나타나는지 선택할 수 있습니다. 매칭된 날짜는 `YYYY-MM-DD`로 정규화합니다. `2026-02-29`처럼 실제로 존재하지 않는 날짜는 무시합니다.

## 필터

Vault 기준 폴더와 태그로 노트를 포함하거나 제외할 수 있습니다. 한 줄에 하나씩 입력합니다. 폴더 규칙은 하위 폴더에도 적용되며 `project` 태그는 `project/calendar` 같은 하위 태그도 매칭합니다. 제외 조건이 포함 조건보다 우선합니다.

## 날짜 클릭 동작

| 모드 | 동작 |
| --- | --- |
| 스마트 열기 | 노트가 하나면 바로 열고 여러 개면 목록 표시 |
| 항상 목록 표시 | 날짜를 선택하고 해당 날짜의 노트 목록 표시 |
| 선택만 | 노트나 목록을 열지 않고 날짜만 선택 |

노트 목록은 캘린더 아래, 팝업 또는 숨김으로 설정할 수 있습니다. 모바일에서 팝업 목록은 하단 시트 형태로 표시됩니다.

캘린더 또는 목록에서 연 노트는 현재 탭, 새 탭 또는 새 분할 영역에 표시할 수 있습니다. Ctrl 또는 Command 키를 누른 채 클릭하면 항상 새 탭에서 열립니다.

## 설정

설정은 다섯 가지 영역으로 구분됩니다.

- **일반:** 언어, 기본 보기, 시작 날짜
- **날짜 매칭:** 날짜 기준, 복수 속성명, 파일명 날짜 형식과 위치
- **필터:** 포함·제외 폴더 및 태그
- **동작:** 날짜 클릭 동작, 목록 위치, 노트 정렬, 노트 열기 위치
- **표시:** 한 주의 시작, 이전·다음 달 날짜, 노트 경로

## 개인정보 및 권한

Calendar of Notes는 Vault 내부에서 로컬로 동작합니다.

- 네트워크 요청 없음
- 분석 및 사용자 추적 없음
- 계정 및 결제 없음
- Vault 외부 파일 접근 없음
- 노트 내용 수정 및 삭제 없음

캘린더를 처음 열거나 복원할 때 날짜 인덱스를 만들기 위해 Markdown 파일 목록을 확인합니다. 노트 본문은 읽지 않고 파일명과 캐시된 frontmatter·태그 메타데이터만 사용합니다. 최초 인덱싱 후에는 Vault 및 Metadata Cache 이벤트를 통해 변경된 파일만 갱신합니다. 폴더와 태그 필터는 로컬에서 적용됩니다.

플러그인 설정은 Obsidian의 표준 플러그인 데이터 API로 저장됩니다.

릴리스 파일은 GitHub Actions에서 빌드하고 암호학적 attestation을 생성합니다. 내려받은 파일은 `gh attestation verify main.js -R GOODJINC/obsidian-calendar-of-notes`와 같은 명령으로 출처를 검증할 수 있습니다.

## 개발

필요 환경:

- Node.js 24 이상
- npm
- 별도의 Obsidian 개발용 Vault

```bash
npm install
npm run dev
```

검증:

```bash
npm run build
npm test
npm run lint
```

프로덕션 빌드는 로컬에 `main.js`를 생성합니다. 이 파일은 Git에서 제외되며 GitHub Release 워크플로가 릴리즈 첨부 파일로 추가합니다.
